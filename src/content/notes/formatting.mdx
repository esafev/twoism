Notes are written in [MDX](https://mdxjs.com), Markdown with components. Text can be _italic_, **bold** or `inline code`.

## Second-level heading

### Third-level heading

> A blockquote, for quotes and asides.

Lists:

1. An ordered list
2. Its second item

Tasks:

- [x] A finished task
- [ ] An open one

Code blocks are highlighted at build time:

```ts
function greet(name: string): string {
  return `Hello, ${name}`;
}
```

Images go into `src/content/notes/assets` and are optimized at build time:
